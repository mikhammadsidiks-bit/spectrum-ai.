SPECTRUM AI — Android-проект

Это стартовая версия приложения для поиска по открытым источникам. Поиск выполняется через внешний браузер.
Приложение не получает доступ к закрытым базам данных, банковским системам или государственным аккаунтам.

Сборка APK:
1. Загрузите содержимое проекта в Git-репозиторий.
2. Подключите репозиторий в Codemagic.
3. Запустите workflow Android.
4. Скачайте APK из Artifacts после успешной сборки.

Требуется JDK 17 и Android SDK (Codemagic предоставляет окружение сборки).
